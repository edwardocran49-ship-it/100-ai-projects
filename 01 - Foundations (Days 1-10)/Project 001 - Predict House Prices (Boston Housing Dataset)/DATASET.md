# Dataset record

- **Name:** Boston Housing
- **Kaggle page:** https://www.kaggle.com/datasets/altavish/boston-housing-dataset
- **Downloaded file:** `data/HousingData.csv`
- **Rows:** 506
- **License shown by Kaggle:** CC0: Public Domain
- **Retrieved:** 2026-10-03
- **Target:** `MEDV`, median value of owner-occupied homes in USD 1,000s

The data contains 13 explanatory columns plus the target. This project uses `RM` for a transparent one-feature baseline; the other columns remain available for a multivariate extension.

The dataset is historically important but includes a variable (`B`) derived from a racially framed assumption. It should be used for education and model-analysis exercises, not as a basis for modern housing policy or consequential decisions.

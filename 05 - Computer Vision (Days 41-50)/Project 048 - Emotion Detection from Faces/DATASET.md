# Dataset record

- **Name:** FER-2013
- **Source:** https://www.kaggle.com/datasets/msambare/fer2013
- **Default evaluation sample:** 560 face images across seven emotion classes
- **Retrieval:** run python download_data.py

The dataset remains in KaggleHub's versioned cache. Images are read from the train folders, normalized, and passed to the course-aligned two-layer CNN.

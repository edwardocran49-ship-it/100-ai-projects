# Project 48: Emotion Detection from Faces

**Author:** Edward Ocran

Train and evaluate a two-layer CNN on a balanced seven-emotion sample from FER-2013.

## Run

```powershell
pip install -r requirements.txt
python download_data.py
python main.py
python -m unittest -v test_project.py
```

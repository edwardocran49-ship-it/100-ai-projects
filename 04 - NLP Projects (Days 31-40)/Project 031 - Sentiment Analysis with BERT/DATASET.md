# Dataset record

- **Name:** IMDb Dataset of 50K Movie Reviews
- **Source:** https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews
- **Evaluation sample:** 200 reviews, balanced between positive and negative labels
- **Retrieval:** run python download_data.py

KaggleHub stores the full dataset in its versioned local cache. The default run draws a reproducible balanced sample and evaluates the pretrained BERT-family classifier; the dataset itself is not copied into Git.

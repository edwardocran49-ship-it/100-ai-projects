# Dataset record

- **Name:** SMS Spam Collection
- **Source:** https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset
- **Records:** 5,572 labelled messages
- **Target:** ham or spam
- **Retrieval:** run python download_data.py

KaggleHub keeps the downloaded file in its versioned local cache. The dataset is used for the stratified train/test evaluation and is not copied into Git.

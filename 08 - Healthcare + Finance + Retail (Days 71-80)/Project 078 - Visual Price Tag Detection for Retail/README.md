# Project 78: Visual Price Tag Detection for Retail

**Author:** Edward Ocran

## Objective

Implement the course workflow for visual price tag detection for retail with inspectable inputs, outputs, and validation.

## Included

- `main.py` — runnable implementation.
- `test_project.py` — behavior test.
- `ANALYSIS_REPORT.md` — detailed findings and charts.
- `INPUTS.md` — controlled image provenance and handling.
- `analysis_assets/` — rendered report figures.

## Run

```powershell
pip install -r requirements.txt
python main.py --help
python -m unittest -v test_project.py
```

The course PDF is not redistributed.

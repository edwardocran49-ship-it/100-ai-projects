# Dataset

The analysis uses two genuine recordings from the official OpenBCI GUI repository: `OpenBCI_GUI-v6-blinks-jawClench-alpha.txt` and `OpenBCI_GUI-v6-meditation.txt`. OpenBCI playback files contain raw, unfiltered EEG samples at 250 Hz. The local `data/` directory is excluded from Git because the meditation file is approximately 27 MB. Run `download_data.py` before the full analysis.

Source: https://github.com/OpenBCI/OpenBCI_GUI/tree/master/OpenBCI_GUI/data/EEG_Sample_Data

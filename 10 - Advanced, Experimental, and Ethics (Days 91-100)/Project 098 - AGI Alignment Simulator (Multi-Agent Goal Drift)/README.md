# Project 98: AGI Alignment Simulator (Multi-Agent Goal Drift)

**Author:** Edward Ocran

## Objective

Implement the supplied course workflow as a reproducible, tested project with inspectable outputs.

## Contents

- `main.py` — project implementation and JSON interface.
- `test_project.py` — targeted behavior tests.
- `ANALYSIS_REPORT.md` — findings, interpretation, and charts.
- `analysis_assets/` — report figures.

## Run

```powershell
pip install -r requirements.txt
python main.py --json
python -m unittest -v test_project.py
```

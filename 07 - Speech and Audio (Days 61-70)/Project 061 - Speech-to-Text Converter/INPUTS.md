# Input record

**Author:** Edward Ocran

The full demonstration accepts a WAV recording through `--audio` and processes it locally with Vosk. The analysis used a RAVDESS speech recording retrieved from Kaggle (`uwrfkaggler/ravdess-emotional-speech-audio`) as a reproducible validation input. This recording is an evaluation input, not a training dataset for this project.

Audio and model files remain outside Git to preserve their original distribution terms.
